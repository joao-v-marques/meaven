Sobre o projeto

O MEAVEN nasceu como um projeto extracurricular para ensinar educação financeira na prática. Em vez de decorar fórmulas, você muda os números e vê na hora o que acontece com o seu dinheiro.

Tudo aqui é simulação: nenhum valor é cobrado, investido ou guardado. Os resultados são estimativas para ajudar você a pensar, não recomendações de investimento.
